## 1. What Was Completed in This Session (v0.7.1)
1. **Floating Action Button (FAB) for QR Scan on Dispatch Desk**:
   - In `src/pages/admin/DispatchPage.vue`, added a prominent Floating Action Button `<q-page-sticky position="bottom-right" :offset="[16, 76]">` with `<q-btn fab color="positive" icon="qr_code_scanner" label="สแกน QR">`.
   - Allows seller to trigger camera QR scanner at any scroll position when inspecting orders at the tailgate.
2. **Deep Root Cause Fix: Unsupported Field Value `undefined` in Firestore**:
   - **Diagnosis**: Firestore `setDoc()` and `updateDoc()` crash with `FirebaseError: Function ... called with invalid data. Unsupported field value: undefined`.
     - In `createRound` & `updateRound`: Products like `NGO` evaluated `sizeTiers: undefined`, and other fruits evaluated `bundles: undefined`.
     - In `revertOrder` & `updateOrderStatus`: Reverting order status passed `completedAt: undefined`.
   - **Structural Zero-Regression Architecture**:
     - Built `sanitizeFirestoreData<T>()` in `src/stores/fruitStore.ts` that recursively cleans all `undefined` keys before any `setDoc` or `updateDoc` write.
     - In `createRound` and `updateRound`, constructed `prodItem` with optional conditional spreading `...(bundles ? { bundles } : {})` and `...(sizeTiers ? { sizeTiers } : {})`.
     - In `updateOrderStatus`, automatically converts any key set to `undefined` into Firestore's native `deleteField()` so fields are cleanly removed in Firestore without crashing, while also deleting the key from local memory state.
3. **Forensic Analysis of `startTime` Error**:
   - Traced `VM3429:2 Uncaught TypeError: Cannot read properties of undefined (reading 'startTime') at et.reportAllChanges`.
   - Verified that `.startTime` does not exist in project source code; it originates from an external browser extension (Web Vitals / Performance DevTools profiler).
4. **Verification**:
   - `pnpm run typecheck` (`vue-tsc --noEmit`): PASSED (0 errors).
   - `pnpm quasar build -m pwa`: PASSED (0 errors).
